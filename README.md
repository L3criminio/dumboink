# DUMBOINK

Projet d'école « Digital Builders » 2026-2027, groupe 3, à Digital Campus Paris.

## Client

DUMBOINK, tatoueur basé à Paris, sans site web existant.

## Objectif du site

Créer un site vitrine présentant le tatoueur et son travail :

- Une galerie de réalisations avec des prix indicatifs.
- Des pages de présentation.
- Un formulaire de demande de projet de tatouage.

Aucun paiement en ligne : les sites marchands sont interdits par l'école.

## Stack

- WordPress.
- Thème développé de zéro (from scratch) : `dumboink`.
- Plugin sur mesure : `dumboink-core`.

Seuls le thème et le plugin seront versionnés, avec les fichiers de documentation et de configuration du dépôt. Le cœur de WordPress et les contenus téléversés sont exclus.

## Règles de l'école

- Vanilla JS uniquement : pas de jQuery.
- Aucun page builder ; Gutenberg est autorisé.
- Mise en page en CSS Grid.
- Aucun secret dans le dépôt.
- Un dépôt Git par groupe sur GitHub, partagé avec l'équipe pédagogique dès le premier coaching (le 17 novembre 2026 à 13 h 30).
- Aucun site marchand ni paiement en ligne.
